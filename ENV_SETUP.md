# Настройка переменных окружения на Amvera

## Где найти переменные окружения

1. Войдите в панель управления Amvera
2. Откройте ваш проект
3. Перейдите в раздел **"Settings"** или **"Environment Variables"**
4. Добавьте каждую переменную отдельно

## Обязательные переменные

### 1. BOT_TOKEN
- **Название:** `BOT_TOKEN`
- **Значение:** Ваш токен от @BotFather
- **Пример:** `8222516136:AAHFC_7lGUXLOR1pgSkM2NUImyA9MPBJL0Y`

### 2. OWNER_ID
- **Название:** `OWNER_ID`
- **Значение:** Ваш Telegram ID
- **Пример:** `6178480183`

## Опциональные переменные

### 3. ADMIN_IDS
- **Название:** `ADMIN_IDS`
- **Значение:** ID админов через запятую
- **Пример:** `6178480183,5283300546`
- **Если не указано:** OWNER_ID автоматически становится админом

### 4. DB_PATH
- **Название:** `DB_PATH`
- **Значение:** `/app/data/studio.sqlite3`
- **Обычно не нужно менять** - Amvera установит автоматически

## Как получить Telegram ID

1. Найдите бота @userinfobot
2. Отправьте ему любое сообщение
3. Он ответит вашим ID

## Как получить BOT_TOKEN

1. Найдите @BotFather в Telegram
2. Отправьте команду `/newbot`
3. Следуйте инструкциям
4. Скопируйте полученный токен

## Пример заполнения в Amvera

| Variable Name | Value | Description |
|---------------|-------|-------------|
| BOT_TOKEN | 8222516136:AAHFC_7lGUXLOR1pgSkM2NUImyA9MPBJL0Y | Telegram bot token |
| OWNER_ID | 6178480183 | Owner Telegram ID |
| ADMIN_IDS | 6178480183,5283300546 | Admin IDs (optional) |
| DB_PATH | /app/data/studio.sqlite3 | Database path (auto) |

## Важно

- **Никогда не храните токены в коде!**
- Используйте только переменные окружения
- Проверьте, что все значения без лишних пробелов
- После добавления переменных перезапустите проект
