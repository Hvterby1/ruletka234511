# Развертывание на Amvera

## Подготовка проекта

Проект уже настроен для развертывания на Amvera.

## Файлы для Amvera

- `amvera.yml` - конфигурация окружения
- `requirements.txt` - зависимости Python
- `Procfile` - команда запуска
- `runtime.txt` - версия Python
- `.dockerignore` - исключения для сборки

## Переменные окружения

В Amvera нужно установить следующие переменные окружения:

1. **BOT_TOKEN** (обязательно) - токен вашего Telegram бота
2. **OWNER_ID** (обязательно) - ваш Telegram ID
3. **ADMIN_IDS** (опционально) - ID админов через запятую
4. **DB_PATH** (опционально) - путь к базе данных (по умолчанию `/app/data/studio.sqlite3`)

## Инструкция по развертыванию

1. **Загрузите проект на Amvera:**
   - Создайте новый проект на Amvera
   - Загрузите все файлы проекта через Git или веб-интерфейс

2. **Настройте переменные окружения:**
   - Перейдите в настройки проекта
   - Добавьте переменные окружения из раздела выше

3. **Запустите проект:**
   - Amvera автоматически соберет и запустит проект
   - База данных будет создана в `/app/data/`

4. **Проверьте работу:**
   - Найдите ваш бота в Telegram
   - Отправьте команду `/start`

## Особенности

- База данных сохраняется в персистентном хранилище Amvera
- Логи доступны в панели управления Amvera
- Автоматический перезапуск при ошибках
- Поддержка HTTPS (Amvera предоставляет)

## Troubleshooting

Если бот не запускается:

1. Проверьте переменные окружения в панели Amvera
2. Посмотрите логи сборки и запуска
3. Убедитесь, что BOT_TOKEN правильный
4. Проверьте, что OWNER_ID указан корректно
